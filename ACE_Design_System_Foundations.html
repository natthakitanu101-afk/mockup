FOUNDATION OVERVIEW

โครงสร้างที่พบชี้ว่าทั้งสองฝั่งใช้ภาษาการออกแบบเดียวกัน แล้วเปลี่ยนเฉพาะสีประจำบทบาท จึงควรดูแลเป็นระบบฐานชุดเดียว แทนการแยกเป็นสอง Design System ที่ค่อย ๆ ต่างกันมากขึ้น

โครงสร้างร่วม

ใช้ Prompt, สเกลตัวอักษร, Secondary, Grey, White, Black และรูปแบบ Component หลักร่วมกัน

02 / Student theme

Student

ใช้สีฟ้าเป็น Primary และไล่สีฟ้าไปม่วงในเมนู เพื่อสื่อบรรยากาศที่สดใสและเข้าถึงง่าย

03 / Teacher theme

Teacher

ใช้สีชมพูเป็น Primary และไล่สีชมพูไปม่วง โดยคงโครงสร้าง Interaction เดียวกับฝั่งนักเรียน

i
ขอบเขตหลักฐาน: ค่า Font, Weight, Size, Hex และ Gradient ในเอกสารนี้ถอดจากข้อความที่ปรากฏในภาพต้นฉบับ ส่วนบทบาทการใช้งานของสีอธิบายจากตัวอย่าง Component ที่เห็นในภาพ โดยไม่เพิ่มชื่อ Token ที่ต้นฉบับไม่ได้ระบุ

COLOR SYSTEM

Primary เปลี่ยนตามกลุ่มผู้ใช้ ขณะที่ Secondary และ Neutral เป็นฐานร่วม กดที่แต่ละ Swatch เพื่อคัดลอกค่าไปใช้งาน
