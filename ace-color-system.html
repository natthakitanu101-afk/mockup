01

Role primaries

สีหลักสามชุดที่แยกพื้นที่ของแต่ละบทบาทออกจากกัน ใช้กับ navigation, header, ปุ่มหลัก และ accent ของหน้านั้น · คลิกแถบสีเพื่อคัดลอกค่า

Teacher

พื้นที่งานประจำวันของครู — เช็กชื่อ ออกเกรด เอกสาร

Base · #CA5D9B
ข้อความบนสี base: ใช้สีดำ · ตัวอักษรขาวใช้ได้เฉพาะขนาดใหญ่

Student

พื้นที่ของนักเรียน — ผลการเรียน เอกสาร คำขอ

Base · #42B1DC
ข้อความบนสี base: ใช้สีดำเท่านั้น — ตัวอักษรขาวไม่ผ่านเกณฑ์ (ดูหัวข้อ 04)

Parent · Shared

พื้นที่ผู้ปกครอง และองค์ประกอบที่ทุกบทบาทใช้ร่วมกัน

Base · #A172FC
ข้อความบนสี base: ใช้สีดำ · โทน 700 รองรับตัวอักษรขาว
02

Foundation

สีพื้นฐานที่ทุกบทบาทใช้ร่วมกัน ไม่เปลี่ยนตามพื้นที่ผู้ใช้ — พื้นหลัง เส้นคั่น ลำดับของตัวอักษร และสถานะปิดใช้งาน

Neutral

ใช้กับพื้นหลัง ตาราง เส้นแบ่ง และตัวอักษร · Warm-50 ใช้เป็นพื้นหลัง section ที่มีตารางข้อมูลหนาแน่น เพื่อลดความแข็งของหน้า

03

Semantic

สีบอกสถานะของงาน ใช้เหมือนกันทุกบทบาท เพื่อให้ครู นักเรียน และผู้ปกครองอ่านสถานะเดียวกันได้ตรงกัน

Error

บันทึกไม่สำเร็จ ข้อมูลไม่ครบ หรือกรอกคะแนนเกินเกณฑ์ที่กำหนด

Warning

คำขอเอกสารรอตรวจ เกรดที่ยังไม่ยืนยัน และรายการที่ใกล้ถึงกำหนดส่ง

Success

เผยแพร่เกรดสำเร็จ บันทึกการเช็กชื่อครบ และคำขอที่อนุมัติแล้ว · ใช้โทน teal เพื่อแยกจากสีฟ้าของนักเรียน ไม่ให้สถานะปนกับสีบทบาท

04

Contrast check

ตรวจคู่สีข้อความบนสีหลักของแต่ละบทบาท เกณฑ์ข้อความปกติ 4.5:1 และข้อความขนาดใหญ่ 3:1 — ผลการตรวจใช้กำหนดกติกาการใช้ตัวอักษร โดยไม่เปลี่ยนค่า token

คู่สีข้อความพื้นหลังอัตราส่วนWCAG AA
ดำ บน Student#000000#42B1DC8.55:1ผ่าน
ขาว บน Student#FFFFFF#42B1DC2.46:1ไม่ผ่าน
ดำ บน Teacher#000000#CA5D9B5.55:1ผ่าน
ขาว บน Teacher#FFFFFF#CA5D9B3.78:1เฉพาะข้อความใหญ่
ดำ บน Parent · Shared#000000#A172FC6.33:1ผ่าน
ขาว บน ดำ#FFFFFF#00000021.00:1ผ่าน
สิ่งที่พบและวิธีรับมือ

ตัวอักษรสีขาวบนสีหลักของนักเรียน (#42B1DC) ได้ค่า 2.46:1 ซึ่งต่ำกว่าเกณฑ์ AA จึงกำหนดเป็นกติกาว่าข้อความบนสีนี้ใช้สีดำเท่านั้น และเมื่อจำเป็นต้องใช้ตัวอักษรขาวให้เปลี่ยนไปใช้โทน 700 แทน · กรณีนี้ทำให้ย้ายการตรวจ contrast มาเป็นขั้นตอนหนึ่งของการกำหนด token ตั้งแต่ต้น แทนการตรวจหลังออกแบบหน้าจอเสร็จ

05

กติกาการใช้งาน

ข้อตกลงที่ทำให้ระบบขยายต่อได้โดยไม่แตกเป็นคนละผลิตภัณฑ์

01
สีบอกบริบท ไม่บอกวิธีใช้

component ทุกตัวทำงานเหมือนกันทุกบทบาท เปลี่ยนแค่สีประจำพื้นที่ ผู้ใช้ที่ข้ามบทบาทจึงไม่ต้องเรียนรู้ใหม่

02
สถานะไม่ยืมสีบทบาท

Error, Warning, Success ใช้ชุดสีของตัวเองเสมอ เพื่อไม่ให้อ่านสับสนระหว่าง “อยู่พื้นที่ใคร” กับ “สถานะเป็นอะไร”

03
ตรวจ contrast ก่อนเลือกโทน

ทุกครั้งที่วางข้อความบนพื้นสี ตรวจค่าตามตารางหัวข้อ 04 ก่อน หากไม่ผ่านให้เปลี่ยนโทน ไม่ใช่เลี่ยงด้วยการขยายขนาดตัวอักษร

04
Neutral คือโครง สีคือป้าย

โครงสร้างหน้าวางบน neutral ทั้งหมด สีประจำบทบาทใช้เท่าที่จำเป็นเพื่อบอกตำแหน่ง ไม่ระบายทั้งหน้า
